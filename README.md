
# BookTracker

Основа iOS-застосунку для ведення списку прочитаних книг (Трекер книг). 
Проєкт виконується в рамках практичних робіт з розробки під iOS.

## Предметна область
Застосунок дозволяє користувачам зберігати інформацію про книги, їхніх авторів та статус читання ("Не прочитано", "Читаю", "Прочитано").
**Основні сутності:**
1. `Book` (Книга) — зберігає інформацію про конкретну книгу.
2. `Library` (Бібліотека/Колекція) — керує списком книг, дозволяє додавати нові, шукати та фільтрувати їх за статусом.

## Технічні вимоги (Practical 1)
- **Xcode:** 27.0+ (або ваша версія)
- **Min iOS:** 27.0+
- **Мова:** Swift

## Реалізована функціональність (Practical 1)
У межах першої роботи реалізовано:
- Базові моделі даних (`struct Book`, `class Library`, `enum ReadingStatus`, `protocol Summarizable`).
- Сценарій створення сутностей, додавання в колекцію, пошук із розгортанням опціоналів (`if let`) та фільтрацію масиву.

## Як запустити
1. Клонувати репозиторій: `git clone https://github.com/Temeka10/iOS-practice1.git`
2. Відкрити `practice-1.xcodeproj` у Xcode.
3. Обрати симулятор (наприклад, iPhone 15 Pro) та натиснути `Cmd + R`.
4. Переглянути консоль Xcode (Console Output) — туди виводиться результат роботи базового сценарію, який запускається під час старту додатку (в `.onAppear`).
